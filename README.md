# Organize AI

Organize AI (formerly Sidechat) is a modern team collaboration platform featuring real-time messaging, AI integration, and a beautiful UI.

## Features

- **Real-time Messaging**: Instant communication with groups and threads.
- **AI Integration**: Built-in AI assistant ("Organize AI") to help with tasks and questions.
- **Modern UI**: Sleek, responsive design with dark mode and custom themes.
- **Secure**: User authentication and private threads.

## Getting Started

1. Install dependencies:
   ```bash
   npm install
   ```
2. Start the development server:
   ```bash
   npm run dev
   ```
